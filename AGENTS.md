# Repository rules

- Keep native iFreeTime JSON configurations and Safari import links only.
- sources/ stores individual configurations; configs.json is their combined list.
- index.html is the dependency-free GitHub Pages import page.
- Keep configuration changes consistent between the combined and individual files.
- The user authorized the 19 IBS originals under originals/; preserve their bytes. Do not upload ITTS, credentials, private local inventories or temporary files.
- Verify JSON parsing and import link targets before publishing.
- Record desktop checks separately from actual iPhone import and reading verification.
- Do not add dependencies, publish updates or delete files without user authorization.
